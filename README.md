# Bettering Claude

Claude Code mods.

## Prompt Master

A **✨ Prompt Master** button above the prompt box that rewrites your prompt into a clearer, stronger one before you send it. See [plugins/prompt-master/README.md](plugins/prompt-master/README.md).

Install:

```
/plugin install prompt-master --marketplace pulkitchaturved-lgtm/Bettering-Claude
```
