# Prompt Master

A Claude Code mod that rewrites your prompts into clearer, stronger prompts before they are sent.

- **✨ Prompt Master** button (just above the prompt box; in a pane on mobile): with a draft in the box it rewrites the draft in place so you can review it and press Enter. **Undo** restores your original. If the box is empty, or the app uses its own input box, one click arms it and your next message is rewritten as you send it.
- **Auto** toggle: rewrite every prompt you send.
- `/prompt-master [text]`: rewrite the given text, or open the button pane. `/prompt-master-auto` toggles auto mode.

Rewrites keep your intent, facts, code and paths exactly. They only make the goal, context, constraints and expected result explicit. They run through your session's own model access.
